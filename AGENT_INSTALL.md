# Agents: install Kraken Agent Bridge from here

The full install, setup and usage instructions are in **[`KrakenAgentBridge/MCP/README.md`](KrakenAgentBridge/MCP/README.md)**. Open it and follow it from step 0.

1. **Step 0** copies the `KrakenAgentBridge` folder from this download into the user's Fantasy Grounds `extensions` folder.
2. **Steps 1 to 7** set you up: Python, the MCP server, the skill, the startup shortcut, the user's steps in FGU, then verify.
3. **Step 9** tells the user they can delete this download.

How to use the bridge once connected: `KrakenAgentBridge/MCP/AGENT_GUIDE.md`.
